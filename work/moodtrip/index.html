MoodTrip — describe the stay, discover the right hotel

MoodTrip turns natural-language travel preferences into relevant hotel recommendations, combining semantic discovery, live hotel information, reviews, pricing context, and direct booking handoffs.

The challenge

Hotel search starts with a feeling, not a filter.

Travelers describe stays in their own words — “romantic but walkable,” “calm, near the beach, good breakfast” — while booking platforms expect checkboxes. MoodTrip closes that gap: it interprets the description, searches a large international hotel inventory, and returns options a traveler can actually compare.

Results combine semantic recommendations with live hotel information, reviews, and pricing context, then hand off directly to booking. The same hotel intelligence is exposed to AI agents through the connected HotelSearchAgent MCP infrastructure.

User flow

From description to booking.

  1. Describe the stay in natural language
  2. Semantic search across live hotel inventory
  3. Compare options with reviews and pricing context
  4. Ask follow-up questions about a hotel
  5. Hand off to a direct booking path

MCP

Connected agent infrastructure.

MoodTrip’s hotel intelligence is also available to AI assistants through the HotelSearchAgent MCP endpoint — 11 tools covering search, intelligence, and utilities, with no API key required.
