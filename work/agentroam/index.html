AgentRoam — AI-ready travel connectivity

AgentRoam is a travel-connectivity platform where travelers can find eSIM data plans, travel gift cards, and airtime, then pay with stablecoins or crypto. Its MCP layer lets AI agents search destinations, compare plans, prepare checkout, create orders after explicit user confirmation, and track delivery.

The challenge

Connectivity for travelers, structure for agents.

Travelers need simple access to international data, while crypto-native users and AI agents need structured ways to search, compare, prepare, and track purchases.

The answer is a travel-connectivity platform combining eSIM data, Gift Cards, Airtime, crypto checkout, and MCP tools — one catalog serving both a human storefront and a machine-readable agent interface.

User flow

From destination to delivered eSIM.

  1. Choose a destination
  2. Compare eSIM plans
  3. Select payment asset and network
  4. Review the order
  5. Confirm before creation
  6. Pay from the user’s wallet
  7. Track payment and delivery

Agent flow

The same journey, exposed as MCP tools.

  1. Search destinations
  2. List plans
  3. Prepare quote
  4. Validate the order
  5. Display a confirmation summary
  6. Create the order only after approval
  7. Track fulfillment

MCP

Transactional tools with a human in the loop.

An MCP layer for searching eSIM destinations, comparing plans, quoting crypto checkout, validating orders, creating orders only after user confirmation, and tracking delivery.

Transaction safeguards

Automation with brakes built in.

Explicit confirmation No order is created until the user reviews a summary and approves it.
One-time confirmation token Each approval maps to a single order — it cannot be replayed.
Quote expiry Prices are quoted for a limited window, so stale quotes cannot be executed.
No custody Users pay from their own wallet; AgentRoam does not hold customer funds.
Merchant-of-record disclosure Checkout states clearly who fulfills the order and processes the payment.
Clear network selection The payment asset and blockchain network are chosen explicitly before payment.
